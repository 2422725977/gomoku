## 项目速览

**一句话介绍**：一款基于 Godot 4 的五子棋人机对战程序，**棋盘大小、连珠数、AI 难度、
执子先后手全部可实时调节**，采用古风木色视觉，内置一个**会随规则自我调整搜索策略与
评估权重**的 Alpha-Beta 剪枝 AI。

### 关键数据

| 维度 | 数据 |
|---|---|
| 代码规模 | 3 个 GDScript，约 1500 行（棋盘层 / 界面层 / 算法层） |
| 外部素材 | **仅 1 个**背景图；字体、音效、木纹、图标全部程序生成 |
| 棋盘规格 | 9 / 11 / 13 / 15 / 17 / 19 路（奇数） |
| 连珠数 | 5 连 / 6 连 |
| AI 搜索深度 | 9 路 5 层 → 19 路 2 层（随尺寸自适应） |
| AI 时间上限 | 2 秒硬超时（困难档实测单步最大 1537 ms） |
| 累计测试断言 | **185+ 条**，全部通过 |
| 修复的真实缺陷 | 8 个（含 2 个「游戏不可玩」级别） |

### 三种典型玩法

| 规格 | 特点 | AI 深度 / 耗时 |
|---|---|---|
| 9×9 · 5 连 | 快棋，格子大、棋子大，一局十几手 | 深度 5 / 465 ms |
| 15×15 · 5 连 | 标准五子棋 | 深度 3 / 28 ms |
| 19×19 · 6 连 | 长局，棋盘大、连珠难 | 深度 2 / 9 ms |

## 快速上手

```bash
# 1. 用 Godot 4.5+ 打开本目录
# 2. 或命令行直接运行：
godot --path . --rendering-driver opengl3
```

启动后进入**开始界面**：

1. 在右侧面板调整玩法（棋盘大小 / 连珠数 / AI 难度 / 执子）
2. 点「开始游戏」
3. 鼠标左键点击棋盘交叉点落子（悬停会显示半透明预览棋子）

## 功能一览

### 玩法
- 棋盘大小 **9 ~ 19 路（奇数）**，连珠数 **5 / 6 连**
- 执子可选：**执黑先行** / **执白后行**（选执白后 AI 执黑先手）
- 三档难度：简单（含 10% 随机失误）/ 普通 / 困难
- 重新开始 / 悔棋（一次退回一整轮）

### 视觉
- 木色羊皮纸回纹背景 + 半透明暖木棋盘
- 楷体/宋体中文排版 + `#3E2723` 深棕文字
- 棋子立体感（外阴影 + 边缘压暗 + 双层高光）
- 悬停幽灵棋子预览、Q 弹落子动画、最后一手红点
- 胜利连线呼吸式闪烁 + 胜负结算弹窗
- 半透明圆角面板（`#FFFFFFAA` + 8px 圆角）

### 交互
- 鼠标点击自动吸附到最近交叉点（半格容差）
- 开始界面可先配置再开局，未开始时棋盘锁定
- 滑动条防抖：拖动中不重建，松手才生效
- 落子音效（程序合成，无音频素材）

## 技术亮点速览

1. **规则自适应 AI** —— 搜索深度随棋盘尺寸收敛（9 路 5 层 → 19 路 2 层）；
   评估权重随连珠数变化（**4 连时活三权重从 1000 提升到 10000**，
   因为「活三 → 活四 → 取胜」的链条更短）
2. **增量式线型评估** —— 棋盘预切为「线」，落子只重算经过该点的 4 条线，
   **叶子评估 O(1)**，这是深度 5 能压进 2 秒的关键
3. **战术预检短路** —— 搜索前先判「我方成连珠 / 对方成连珠必挡 / 我方成活四」，
   实测多次以 **1 ms、深度 0** 直接算出必胜手
4. **Zobrist 置换表** —— 单 64 位整数打包分数/深度/标志/着法，含 mate-ply 修正，
   20 万条封顶
5. **视觉与棋局状态严格分离** —— 所有动画通过监听已有信号驱动，
   不侵入落子逻辑；AI 模块可整体替换
