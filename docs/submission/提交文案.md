## 二、作品简介

### 版本 A（约 260 字，推荐）

```
一款基于 Godot 4 的五子棋人机对战程序。玩家可在右侧面板实时调整棋盘大小
（9/11/13/15/17/19 路）、连珠数（5 或 6 连）、AI 难度与执子先后手，同一套程序
覆盖从 9 路快棋到 19 路长局的多种玩法。

核心亮点是「规则自适应 AI」：搜索深度随棋盘尺寸自动收敛（9 路搜 5 层、19 路
收敛到 2 层），评估权重随连珠数动态调整（4 连规则下活三权重提升 10 倍，因为
「活三→活四→取胜」的链条更短）。配合增量式线型评估（叶子节点 O(1)）、Zobrist
置换表与战术预检短路，在 2 秒时限内即可完成深度 5 的搜索。

视觉采用木色羊皮纸底纹与楷体中文排版；除一张背景图外，字体、音效、木纹纹理
全部由代码生成，无额外素材依赖。
```

### 版本 B（约 120 字，字段较短时用）

```
基于 Godot 4 的五子棋人机对战程序。棋盘大小、连珠数、难度、执子先后手均可实时
调整；内置的 Alpha-Beta 剪枝 AI 会随规则自我适配——搜索深度按棋盘尺寸收敛，
评估权重按连珠数调整。木色古风视觉，除背景图外零素材依赖。
```

### 版本 C（一句话，60 字）

```
一款棋盘大小、连珠数与 AI 难度都可实时调节的五子棋程序，AI 会随规则自动调整
搜索策略与评估权重。
```

## 四、演示视频

位于 `docs/submission/demo.mp4`。

### 分镜（共 8 段，约 2 分钟）

| # | 内容 | 展示的功能 |
|---|---|---|
| 1 | 开始界面，点击「开始游戏」 | 标题卡、按钮悬停放大、淡出转场 |
| 2 | 15 路 5 连对局 4 手 | 悬停幽灵棋子、落子弹跳、AI 应手与耗时显示 |
| 3 | 拖动「棋盘大小」滑块 | 拖动中棋盘不重建、松手才生效（防抖） |
| 4 | 9 路快棋 3 手 | 几何自适应（格宽 70px / 棋子半径 28px）、AI 深度 5 |
| 5 | 切到 19 路 + 6 连 + 困难 | 三种参数联动、几何缩到 31px / 12px |
| 6 | 切换「执白 · 后行」+ 悔棋 | AI 执黑先手、玩家执白落子、悔棋 |
| 7 | 构造五连取胜 | 获胜连线呼吸式闪烁 + 结算弹窗淡入缩放 |
| 8 | 重新开始 | 一键重开 |

### 如需自行重录

```bash
# 1. 用 Godot Movie Maker 录制（固定 30fps，确定性逐帧输出）
godot --path . --rendering-driver opengl3 --audio-driver Dummy \
      --write-movie docs/submission/demo.avi --fixed-fps 30 \
      res://tools/Demo.tscn

# 2. 用 ffmpeg 编码为 mp4
ffmpeg -y -i docs/submission/demo.avi -c:v libx264 -preset slow -crf 20 \
       -pix_fmt yuv420p -movflags +faststart docs/submission/demo.mp4
```

`tools/demo.gd` 是分镜脚本，改里面的时间轴即可调整演示内容。
注意：Godot 帧缓冲**不包含操作系统光标**，脚本里自绘了一个箭头光标与点击涟漪，
否则视频里看不到鼠标在点哪里。

### 运行环境

- 引擎：Godot **4.5+**（开发验证于 4.7.2-stable）
- 平台：Windows / macOS / Linux（未使用平台相关 API）
- 运行：用 Godot 打开工程目录直接运行，或
  `godot --path . --rendering-driver opengl3`

### 操作说明

| 操作 | 方式 |
|---|---|
| 落子 | 鼠标左键点击棋盘交叉点（自动吸附最近点） |
| 调整玩法 | 右侧「玩法设置」面板：棋盘大小 / 连珠数 / AI 难度 / 执子 |
| 重新开始 / 悔棋 | 右侧按钮 |
